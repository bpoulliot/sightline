# Examples

Committed, synthetic, and safe to publish. Nothing here came from a live Canvas instance.

- `sample-course/` — a hand-built course in Sightline's normalized document model, small enough to
  read, with deliberate defects so every detector has something to find. It is the test suite's
  fixture and it is what a new user runs without a Canvas token. See `sample-course/README.md` for
  what is planted in it and why four detectors are marked as not yet covered.
- `sample-report/` — what Sightline produces from `sample-course/`: the PDF course report
  (`report.pdf`), the workbook (`review.xlsx`), and what they were made from — the review file the
  run saved (`review.json`) and `render.json` (when the review was opened, which model located the
  evidence, and the versions of the libraries that rendered the PDF). The links in them point at
  `canvas.example.edu`, which is not a real Canvas.

```sh
python -m sightline.acquire --bundle examples/sample-course
```

`sample-report/` is regenerated by `scripts/make-sample-report.sh`, which runs the sample course
through the normal batch run, opens its review and exports it through the gate, all in a scratch
data folder, and then copies the result here. The copy is the script's: no module in
`src/sightline` may open a file for writing except `sightline/paths.py`, and that module writes only
under the data root, so there is no code path in the package that could put anything here.
`tests/test_sample_report.py` re-renders the committed review file and compares the result with what
is committed — see the README's *The sample report* for when it has to be regenerated.

Real course exports never live here. They go under `SIGHTLINE_DATA_DIR` (default `./data`), which
is gitignored in full.
