A row bound to a capability tag is answered from what the detectors behind that tag observe; a row bound to nothing is answered from passages a model locates and quotes. Bindings are an accelerator, not a prerequisite: a run works with none. Here a model proposes bindings, a person accepts the ones they want, and every run started afterwards uses the accepted ones. The rubric file Sightline ships with is never changed; what is accepted is kept under the data root, with who accepted it and when.
