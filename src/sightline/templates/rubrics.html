Rubrics

The rubrics a run can be reviewed against. On each rubric's page a model can propose bindings from its rows to the capabilities Sightline's detectors observe, and a person accepts the ones they want, once per rubric, never per course. A run never waits on this: it uses the bindings accepted so far, and the shipped rubric's own where none are.
