New run

Paste Canvas course URLs or bare course ids, or upload a CSV with a column of either. A URL that points at a page, an assignment or a module still resolves to its course. Resolving starts nothing: it reports what each reference resolved to, and the courses Canvas resolved come back with a rubric to pick and a Start button. A course bundle is reviewed from the command line, with python -m sightline.batch run --bundle.
